# 工具交互覆盖

在既有 MASTER.md 的颜色、间距和双主题规则下，根据实际任务安排界面。`src/tools/catalog.ts` 是分类与交互类型的唯一映射入口；重分类不更改已有 URL。

`src/tools/experiences.ts` 为全部 134 个路由逐项指定页面策略，`task-pages.css` 和 `specialized-pages.css` 管理内容自适应布局。相似项目的交互参考、专用工具页面和验收范围见 [工具页面交互](../../../docs/tool-interactions.md)。

| 类型 | 布局与交互 |
| --- | --- |
| 文本 | 输入和结果并列，手机纵向排列；复制、导入、清空、下载，输入后自动更新 |
| 代码 | 本地等宽编辑区、行号、语言和字符数量；只读结果可选择复制 |
| 对比 | 两份有独立名称的输入，完整宽度的差异结果 |
| 表格 | 结构化数据输入；CSV/TSV 结果可切换表格预览与文本，预览分隔符可调 |
| 图片 | 文件预览、参数和显式处理按钮；原生 Canvas 编辑器提供直接预览与导出 |
| PDF | 文件列表、可通过按钮排序、处理参数、预览及下载；表单设计可点击添加控件 |
| 音视频 | 浏览器媒体预览与播放控件、裁剪范围或速度等参数、显式执行 |
| 日期 | 原生日期、时间输入与时区选项，修改后自动计算 |
| 计算器 | 有名称的参数、单位和求解目标，结果区域突出展示 |
| 生成器 | 参数优先，生成结果可复制下载，并提供重新生成按钮 |

图片缩放采用独立的预览加参数侧栏，不展示空结果框；PDF 拆分和旋转使用可点选的页缩略图；音视频裁剪可播放选区并输入精确秒数；Unix 时间戳使用日期选择器与单位切换；bcrypt 使用生成和校验两个明确表单。文件结果在输入或参数改变后失效。输入框标题保持简短，完整说明通过点击帮助查看，示例和高级参数渐进展开。

文件工具避免在修改参数或切换语言时自动重新运行 WASM、OCR 或模型推理。执行中显示状态并禁用重复执行；异步失败在操作附近显示错误。文本统计采用数值卡片，JSON 校验采用明确成功、失败和空状态。

控件使用原生 label、button、input、select、dialog；菜单支持方向键、Escape 和焦点恢复。按浅色、深色及减少动态效果分别检查；桌面输入结果并列，手机单列。
