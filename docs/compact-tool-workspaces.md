# 工具页紧凑布局

所有工具共用紧凑页头，收藏和常用操作与标题并排，说明使用一行摘要。手机可显示两行摘要，较长按钮组在窄屏换行。

PDF 编辑器、表单设计和图片编辑器的文件操作放入公共页头。文本工具的示例和参数重置也使用同一操作区。React portal 保留原工具和 Formik 的上下文。

PDF 编辑器在未上传时展示紧凑的文件入口，上传后按可见视口的剩余空间计算高度，调整窗口或页头换行时同步更新。表单设计的导出和清空也并入页头。

PDF 编辑器的 PDFium WASM 使用安装版本中提供的资源随项目打包，按需从同站点加载，避免外部引擎资源无法下载而一直加载。界面与签名外观使用系统字体。保留现有编辑 SDK 和工具能力，没有增加 UI 框架；图章和特定文档的回退字体仍沿用 SDK 的资源配置。

验证包含全部工具在 1440px 与 375px 下的入口、横向溢出及页头位置，另有 PDF 真实页面渲染、多个屏幕宽度下的编辑区高度、文件清空、示例载入和重置参数的回归。

实测 1440×900 下，PDF 编辑器页头为 85px，编辑区从顶部约 115px 开始，延伸至视口底部上方 16px。全部工具的桌面验收约束为页头不超过 120px、工作区起点不超过 155px。
