# XFTools 界面设计规范

本次重设计继续使用 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。本轮运行 `productivity dashboard minimal --design-system` 与 `forms lazy loading --stack react`，结合 Flat Design 对原生控件及快速反馈的建议，保留现有 Minimalism & Swiss Style 主规范的网格、语义颜色和功能优先原则。

## 视觉基础

- 工作区使用浅蓝底色、深蓝色操作和蓝紫渐变。侧栏、搜索和移动抽屉使用半透明表面与背景模糊。
- 字体：系统字体，英文 Segoe UI、中文 PingFang SC / Microsoft YaHei；不依赖远程字体。代码使用编辑器等宽字体。
- 颜色：通过 `src/components/index.css` 的语义变量统一定义，交互和布局规则在 `src/components/workbench/refinements.css`。原生控件位于 `src/components/ui/`，不依赖组件框架。
- 间距以 4 / 8px 为基准，内容面板圆角 16px，表单圆角 8px。卡片使用浅色描边和轻阴影，输入控件使用实色背景。
- 图标：工作台使用同一套本地 SVG 线性图标；图标与文本同时出现时隐藏装饰图标的无障碍语义。

## 页面与交互

- 桌面：固定侧栏、工具搜索、精选入口、分类与工具卡片；移除顶部栏，侧栏底部处理状态与版本号同行对齐。
- 移动端：抽屉导航，工具卡片和输入输出纵向排列。
- 搜索：名称、说明、关键词匹配；地址栏保存查询；使用 React `useDeferredValue`；Ctrl/Cmd+K 聚焦。
- 收藏与最近使用：仅存本机，多个组件与浏览器标签页保持同步；提供明确空状态。
- 工具详情按任务提供面包屑、说明、收藏、输入输出、选项与示例。详见 `design-system/xftools/pages/tools.md`。
- 每个工具路由都有对应的页面策略。缩放、PDF 选页、音视频裁剪和时间戳使用专门控件。详见 [工具页面交互](tool-interactions.md)。
- 文本和日期工具按输入自动更新。文件工具先选择、预览和设置参数，再点击处理。
- 批量图片、PDF、音视频输入共享文件列表；支持键盘可操作的上下移排序、移除与清空，处理顺序与列表顺序一致。
- 图片编辑使用 Canvas，提供旋转、翻转、百分比裁剪、色彩调整、文字标注、撤销、重置与 PNG/JPEG/WebP 导出。PDF 表单支持点击或拖动添加控件、编辑内容和位置、导出交互表单。
- 仅提供简体中文界面，不保留旧的英文与主题偏好。

## 可访问性与验收

项目标识统一使用 XFTools。界面不提供语言和主题切换；手机导航抽屉支持键盘关闭与焦点恢复。收藏、最近使用及分类页面保留主标题，目录区仅展示数量或搜索结果，避免重复标题。

工具界面与示例的源文案通过 `src/i18n/uiText.ts`、中文 `ui.json` 及参考资源映射为中文。用户输入和处理结果保留原文。XFTools 与品牌标语保留英文，操作名称和反馈使用中文。`npm run i18n:check` 检查缺少的中文资源。首页加载工具元数据，详细选项与示例按工具所属命名空间加载。

提供跳转链接、语义链接和按钮、可见键盘焦点、控件名称与收藏按下状态；移动端主要操作至少 44px。支持 `prefers-reduced-motion`；375 / 768 / 1024 / 1440px 布局无横向溢出。检查浅色界面及侧栏的阅读对比度。工具目录分批展示，避免一次渲染所有工具。
