# 界面简化与问题修复

工作台固定使用简体中文和蓝色浅色外观。启动时清理旧的语言与主题偏好。

工具箱在同一清单展示全部工具。桌面和手机的顶部导航都提供工具搜索，品牌链接可返回工具箱。旧分类地址仍可访问对应的工具清单。

工具卡片的标题打开工作台，常用操作直达相应模式。文件工作台在独立标签页打开，可同时保留多个编辑任务。工作台内的返回按钮直达工具箱。

`Ctrl/⌘ + K` 聚焦搜索。`Enter` 打开最匹配的工具或常用操作，`Escape` 清除搜索。

取消英文界面后，中文资源按工具类别延迟加载。原英文资源仅作为部分旧控件源文本的中文映射参考，不注册成可选界面语言，也不生成英文工具目录。

修复了共享控件中有条件调用 Hook 的问题，并让主题相关样式通过一致的上下文读取。还修复了异常包装丢失原始原因、空选项类型、无用初值与未使用代码等检查问题；原生控件适配层明确消费不支持的兼容属性，避免将其传递到 DOM。未关闭检查规则来消除报错。

工作台回归包含工具清单、常用操作直达、键盘搜索，以及桌面和手机布局。
