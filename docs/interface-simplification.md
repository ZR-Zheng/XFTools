# 界面简化与问题修复

按最新要求，工作台固定使用简体中文与浅色外观，不提供英文或主题切换。启动时会清理旧的语言、主题偏好，避免旧用户仍看到英文或深色页面。XFTools 品牌和原有英文宣传语保持原文。

顶部栏整块移除，工具页仍保留页面自身的面包屑。手机端使用独立的导航按钮打开侧栏抽屉，支持 Escape 关闭和焦点恢复。

工具页底部不再显示其他工具推荐。首页、侧栏和装饰区移除已取消的宣传标语，目录与精选区不再展示宣传副标题和注册提示。

侧栏底部仅保留处理状态与版本号：同一行、垂直居中、两端对齐，始终位于分类滚动区下方。主题按钮不再显示。首页、工具页、预览区、页脚和帮助说明均移除重复的本地处理宣传；页面不再显示 MIT 标识。

取消英文界面后，中文资源按工具类别延迟加载。原英文资源仅作为部分旧控件源文本的中文映射参考，不注册成可选界面语言，也不生成英文工具目录。

修复了共享控件中有条件调用 Hook 的问题，并让主题相关样式通过一致的上下文读取。还修复了异常包装丢失原始原因、空选项类型、无用初值与未使用代码等检查问题；原生控件适配层明确消费不支持的兼容属性，避免将其传递到 DOM。未关闭检查规则来消除报错。

验证覆盖类型检查、生产构建、中文资源检查、83 个单元测试文件的 758 项测试，以及工作台和原有端到端浏览器测试。入口巡检遍历全部 134 个工具的桌面和手机布局；新增回归验证侧栏状态与版本号的中心线一致、旧偏好清理、切换入口不存在和导航抽屉焦点恢复。

全仓库 ESLint 现为 0 错误、0 警告；不再沿用前一轮落地记录中的历史 lint 未通过状态。
