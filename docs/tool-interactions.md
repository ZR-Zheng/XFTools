# 工具页面交互与参考

本轮针对“调整图像大小有大片留白”和工具操作不顺手的问题，逐一登记了全部 134 个工具的页面策略。分类和执行方式由 `src/tools/catalog.ts` 管理，每条路由的页面布局、输入类型、常用参数、示例占位及操作名称由 `src/tools/experiences.ts` 明确指定；单元测试检查两个目录完全一致，新增工具不能遗漏页面配置。

## 页面行为

- 图片缩放：导入区按内容确定高度，不渲染空结果面板；预览桌面最高 370px、手机 235px。宽度和高度都可作为锁定比例的基准；批量图片分别保留各自的比例，支持单张下载与 ZIP 下载。
- 文本与代码：输入和输出并排；短数值、时间表达式采用紧凑输入。列表默认每行一项，分隔方式可直接切换，符号模式正确解释 `\n` 和 `\t`；正则模式保留正则原文。
- 参数：常用选项直接展示，其他选项进入“高级选项”；说明放在可点击的帮助中，不使用长段说明充当输入框标题。示例可一键载入，文件类示例只改变预设，保留已导入文件。
- 页头仅显示简短用途说明，避免手机端被长段工具介绍占满；完整说明保留在使用说明中。
- 文件处理：未上传时隐藏结果面板，处理按钮显示实际操作名；修改文件或参数后，旧结果失效，必须重新处理才能下载，避免保存过期结果。
- PDF：点选页面和输入页码同步；“全选”“清空”有可见按钮，空选区不能提交。分页加载缩略图，避免大文档一次渲染全部页面。
- 音频：浏览器支持解码且文件不超过 100MB 时绘制波形；其他格式仍保留原生播放器和文件处理。波形使用 Web Audio 和 Canvas，无新增依赖。
- bcrypt：输入改变后清除旧匹配状态；生成采用显式按钮，避免每次按键执行耗时哈希；保留粘贴与显示密码功能。
- 日期：秒和毫秒切换保留同一时刻，UTC 与本地时区明确区分；无效输入清空结果并显示错误。

## 验证范围

浏览器测试检查全部 134 个路由在 1440px 与 375px 的加载、运行时错误和横向溢出；另有缩放实际 PNG 尺寸、混合比例批量 ZIP、PDF 实际提取页数、参数修改后结果失效、波形与裁剪控制、时间戳双向转换、bcrypt 匹配、中文默认、英文切换与主题回归。

全部入口巡检不等于逐个格式的完整处理验证；大型视频转码、在线模型下载、所有 HEIC/GIF 编码组合仍需使用相应真实文件验证。
